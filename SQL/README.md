# SQL Analysis

This folder contains SQL-based data analysis projects using PostgreSQL.

Each file focuses on a specific analytical concept and demonstrates
real-world data investigation, cleaning, and interpretation.

## Contents

- `select-basic.md`  
  Basic data inspection using SELECT, ORDER BY, and LIMIT.

- `counts_and_distribution.md`  
  Record counts, distinct values, GROUP BY frequency analysis,
  and percentage distributions.

- `health_duplicates.md`  
  Duplicate detection strategies using DISTINCT, GROUP BY, CTEs,
  and temporary tables.

- `summary_statistics_weight.md`  
  Summary statistics (min, max, mean, median, mode, variance,
  standard deviation) with outlier handling and reasoning.

## Tools Used
- PostgreSQL
- SQLPad / DuckDB UI
- Markdown documentation

Focus is placed on **thinking like a data analyst**, not just writing SQL.
